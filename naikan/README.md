# 内管責 過去問道場

内部管理責任者資格試験対策の一問一答アプリ。
学習サイトの理解度チェックテスト（第1章〜第8章）と習熟レベルチェックテスト（第1〜3回）、
計709問を、単元別の順番演習・範囲指定シャッフル・章ごとのランダム10問で演習できる。
「金財試験 過去問道場」（`../kinzai/`）の姉妹アプリ。

- 公開URL: `https://ichigo0123456789-ai.github.io/naikan/`
- 依存なしの静的サイト（HTML/CSS/JS のみ）。ビルド不要。

## 問題データの作り方

`data/ch1.js`〜`ch8.js`, `data/level.js` は学習サイトのテスト結果画面を保存したHTMLから生成する
（手で編集しない）。

```
node naikan/tools/convert.js "G:\マイドライブ\Claude\内部管理責任者（内管責）\参考資料"
```

- 対象ファイル: `【N章】理解度チェック①.html` … / `【習熟レベル】第①回.html` …
- 取り込むのは問題文・選択肢・正解（`（正解）` マーク）・解説のみ。受験時の解答・正誤・配点は取り込まない
- 小問表（イ．／ロ．／ハ．）は「イ．本文」の行に展開、`<br>` は改行、解説末尾の「PDFテキスト」「復習」リンクは除去
- 選択肢がちょうど2つで「正しい記述である／誤った記述である」または「○／×」の問題は〇×形式に、それ以外は多肢選択に変換
- 期待問数（合計709）と一致しない・正解が1つでない・禁止文字列を含む場合は終了コード1

## 問題データの形式

各ファイルは `{ subject, name, short, units: [...] }` を定義し、
各単元の `questions` に1問1オブジェクトで書く。2形式に対応:

```js
// 〇×問題
{ t: "ox", q: "問題文", a: true, exp: "解説" },
//   a: true = 〇（正しい）, false = ×（誤り）

// 多肢選択（2〜5択。選択肢は c の要素数で決まる）
{ t: "mc", q: "問題文", c: ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  a: 1,   // 正解の index（0始まり。a:1 なら②が正解）
  exp: "解説" },
```

演習問題ファイル（`data/ex/chN.js`）の形式:

```js
window.NAIKAN_EX = window.NAIKAN_EX || {};
window.NAIKAN_EX.ch1 = { id: "practice", name: "演習問題", questions: [ ... ] };
```

### 注意

- **各単元の配列の並び順がそのまま問題番号・学習履歴のIDになります**（ID = `ch1/check1/3` 形式）。
  追加は末尾へ。途中への挿入・削除をすると既存の解答履歴がずれます。

## 機能

- **順番に解く**: 分野タブ（1章〜8章・習熟）→ 単元選択 → 問題番号グリッド（正誤・チェック状況を色表示）
  から好きな問題を選んで順番に演習。タブの下に正式な章名を表示
- **ランダム10問**: 各章タブの「この章からランダム10問」（習熟タブは「3回分からランダム10問」）で、
  その章の全単元（理解度チェック＋演習問題）から10問をシャッフル出題（シャッフル欄の設定は変えない）
- **シャッフルで解く**: 単元ごとのチェックボックスで出題範囲を指定（分野単位の全選択あり、
  選択状態は保存）、出題範囲フィルタ（すべて / 間違えた問題 / 未解答 / チェック済み）、
  出題数（10 / 25 / 50 / すべて）
- 演習中は画面上部に**途中経過の正答率**を常時表示
- 解答直後に正誤判定＋解説表示、「あとで見直す」チェック
- 結果画面（正答率・解答一覧・間違えた問題の再挑戦）
- 成績画面: 分野・単元ごとの正答率、週別の成績、履歴リセット
- 解答履歴は `localStorage`（`naikan-dojo-v1` / `naikan-dojo-user-<id>`）に保存。
  同一オリジンの金財アプリ（`kinzai-dojo-*`）とは別キーなので混ざらない
- キーボード操作: 〇× = `O` / `X`、多肢選択 = `1`〜`5`、`Enter` = 次へ、`←`/`→` = 前後の問題
- **ログイン・成績のサーバー同期**: 金財試験 過去問道場と同じ Google Apps Script を共用し、
  ID＋PIN のアカウントも共通。セットアップ手順は `../kinzai/gas/SETUP.md` を参照
  （このアプリ用の `gas/` はない）。`config.js` の `NAIKAN_SYNC_URL` を空にすると
  ログインUIは表示されず端末内保存のみで動作する
