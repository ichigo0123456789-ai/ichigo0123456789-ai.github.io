# 変額・外貨建 過去問道場

生命保険の **変額保険販売資格試験** と **外貨建保険販売資格試験** の対策用一問一答アプリ。
模擬テスト（各2回）と章別問題を、単元別の順番演習・範囲指定シャッフル・分野ごとのランダム10問で演習できる。
「金財試験 過去問道場」（`kinzai/`）・「内管責 過去問道場」（`naikan/`）の姉妹アプリ（`naikan/` をベースに作成）。

- 公開URL: `https://ichigo0123456789-ai.github.io/hengaku/`
- 依存なしの静的サイト（HTML/CSS/JS のみ）。ビルド不要。

## 分野（タブ）構成

| 順 | subject | タブ表示 | 分野名 | グローバル名 | ファイル | 単元 |
|---|---|---|---|---|---|---|
| 1 | `hengaku_moshi` | 変額 模試 | 変額保険 模擬テスト | `SEIHO_HENGAKU_MOSHI` | `data/hengaku-moshi.js` | `round1`「第1回」, `round2`「第2回」 |
| 2 | `hengaku_ex` | 変額 章別 | 変額保険 章別問題 | `SEIHO_HENGAKU_EX` | `data/hengaku-ex.js` | `ch1`〜`ch4`「第N章 章名」 |
| 3 | `gaika_moshi` | 外貨建 模試 | 外貨建保険 模擬テスト | `SEIHO_GAIKA_MOSHI` | `data/gaika-moshi.js` | `round1`, `round2` |
| 4 | `gaika_ex` | 外貨建 章別 | 外貨建保険 章別問題 | `SEIHO_GAIKA_EX` | `data/gaika-ex.js` | `ch1`〜`ch6` |

- 各分野の末尾に仮想単元「全部通し（N問）」（id `all`）を置く。全単元を連結したもので、
  問題・履歴は元の単元と共有する（シャッフルの範囲ツリーと成績の集計には出さない）
- データファイルが無い分野はタブを作らない（`<script>` の404はコンソールに出るだけで動作に影響しない）

## 問題データの形式

各ファイルは分野オブジェクトを1つ定義する。

```js
window.SEIHO_HENGAKU_MOSHI = {
  subject: "hengaku_moshi", name: "変額保険 模擬テスト", short: "変額 模試",
  units: [
    { id: "round1", name: "第1回", questions: [ ... ] },
    { id: "round2", name: "第2回", questions: [ ... ] },
  ]
};
```

各単元の `questions` に1問1オブジェクトで書く。2形式に対応:

```js
// 〇×問題
{ t: "ox", q: "問題文", a: true, exp: "解説" },
//   a: true = 〇（正しい）, false = ×（誤り）

// 多肢選択（2〜10択。選択肢は c の要素数で決まる）
{ t: "mc", q: "問題文", c: ["選択肢1", "選択肢2", "選択肢3"],
  a: 1,   // 正解の index（0始まり。a:1 なら②が正解）
  exp: "解説",
  img: "data/img/hengaku-r1-q06.png",   // 任意。問題文の下に表示（hengaku/ からの相対パス）
  topic: "出題テーマ" },                 // 任意。アプリは表示しない（データ分析用）
```

- `q` / `exp` 内の `\n` は改行として表示する
- `calc: true` の問題があると「計算問題」フィルタ・仮想単元が出る（1問もなければ非表示）

### 注意

- **各単元の配列の並び順がそのまま問題番号・学習履歴のIDになります**（ID = `hengaku_moshi/round1/3` 形式）。
  追加は末尾へ。途中への挿入・削除をすると既存の解答履歴がずれます。

## 機能

- **順番に解く**: 分野タブ（変額 模試・変額 章別・外貨建 模試・外貨建 章別）→ 単元選択 →
  問題番号グリッド（正誤・チェック状況を色表示）から好きな問題を選んで順番に演習
- **ランダム10問**: 各タブの「この分野からランダム10問」で、その分野から10問をシャッフル出題（シャッフル欄の設定は変えない）
- **シャッフルで解く**: 単元ごとのチェックボックスで出題範囲を指定（分野単位の全選択あり、選択状態は保存）、
  出題範囲フィルタ（すべて / 間違えた問題 / 未解答 / チェック済み）、出題数（10 / 25 / 50 / すべて）
- 演習中は画面上部に**途中経過の正答率**を常時表示。解答直後に正誤判定＋解説表示、「あとで見直す」チェック
- 問題に `img` があれば問題文の下（演習画面・結果の解答一覧）に図を表示
- 結果画面（正答率・解答一覧・間違えた問題の再挑戦）
- 成績画面: 分野・単元ごとの正答率、週別の成績、履歴リセット（このアプリの分野の記録だけを消す）
- 解答履歴は `localStorage`（`seiho-dojo-v1` / ログイン中は `seiho-dojo-user-<id>`、ログイン情報は `seiho-dojo-account`）に保存。
  同一オリジンの金財（`kinzai-dojo-*`）・内管責（`naikan-dojo-*`）とは別キーなので混ざらない
- キーボード操作: 〇× = `O` / `X`、多肢選択 = `1`〜`9`・`0`（10番目）、`Enter` = 次へ、`←`/`→` = 前後の問題
- **ログイン・成績のサーバー同期**: 金財・内管責の過去問道場と同じ Google Apps Script を共用し、
  ID＋PIN のアカウントも共通。セットアップ手順は リポジトリの `kinzai/gas/SETUP.md` を参照
  （このアプリ用の `gas/` はない）。`config.js` の `SEIHO_SYNC_URL` を空にすると
  ログインUIは表示されず端末内保存のみで動作する
