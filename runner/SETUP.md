# 座席オートリザーブ — セットアップ（配布版クイックスタート）

サイト（プランを組む）＝ https://ichigo0123456789-ai.github.io/cinema/
実際に席を確保するのは、**この runner を入れたあなたのPC**です。
会員情報・カード情報は**サイトには一切入りません**。すべてあなたのPCの中だけで動きます。

---

## 仕組み（3行）

1. **サイト**で 映画館→日時→座席 を選び、[コマンドをコピー] を押す
2. **自分のPCのターミナル**にそのコマンドを貼り付けて実行
3. 発売の瞬間に席を最速で確保 → **自分のブラウザ**で決済画面が開く（支払いは自分で）

> スマホからは実行できません（PCの runner とブラウザが必要）。
> スマホはプランを組む用として使い、実行・支払いはPCで行ってください。

---

## 用意するもの

- **Node.js（LTS版）** … https://nodejs.org/
- **普段使いのブラウザ**（Brave / Chrome / Edge のどれか）
  … ログイン・カード情報が保存されているブラウザを使うと、決済がスムーズです。
  どれも無ければ内蔵 Chromium で開きます（その場合ログインは都度手入力）。
- 使う映画館の**会員ID / パスワード**（会員先行を使う場合。ゲスト購入で足りるチェーンは不要）

## セットアップ（初回だけ）

リポジトリを ZIP でダウンロードするか `git clone` して展開したら:

### Windows（PowerShell）
```powershell
cd <展開したフォルダ>\runner
./setup.ps1
```
※ 実行がブロックされたら一度だけ: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`

### macOS / Linux
```bash
cd <展開したフォルダ>/runner
bash setup.sh
```

これで「依存インストール → ブラウザ準備 → `.env` 作成」まで自動で終わります。

### 会員情報を入れる
`runner/.env` を開き、**使う映画館の行だけ**埋めます（`.env` は git 管理外＝公開されません）。
```
KINEZO_EMAIL=...      # T・ジョイ系（横浜/新宿バルト9/京都/梅田/横浜ブルク13）
KINEZO_PASSWORD=...
C109_ID=...           # 109シネマズ（川崎/プレミアム新宿）
C109_PASSWORD=...
# TOHO / チネチッタ / サンシャイン / eigaland はゲスト購入で座席指定まで進めます（会員先行を使う場合のみ設定）
```

## 使ってみる

まずは**練習（席は取らない）**。末尾の `--dry` が「確保の直前で止める」モードです。
リポジトリの**ルートフォルダ**で実行してください。

```bash
node runner/reserve-hybrid.js --theater shinbungeiza --date 2026-08-25 \
  --title "作品名" --time 17:30 --seats "A-1,A-2" --dry
```

- `--seats "A-1,A-2 / B-5,B-6"` … `/` 区切りで第2候補以降も指定できます
- `--at "2026-08-25T21:00:00+09:00"` … 発売時刻に自動発火（発売前から待機）
- `--browser chrome` … 決済ブラウザを明示指定（既定は Brave→Chrome→Edge 自動検出）

本番は `--dry` を外すだけ。席を確保したら、**券種選択の直前**で止まり、あとは
自分のブラウザで券種・支払いを進めます（券種の自動選択はしません＝価格ミス防止）。

## 安全のための約束（重要）

- **会員情報・カード情報はサイトに入力しない。** すべて `runner/.env` と自分のブラウザの中だけ。
- **`.env` は絶対にコミット・共有しない**（`.gitignore` 済み）。人に渡すときは空の `.env.example` だけ。
- **1アカウント1予約**。多重接続・連打・行列スキップはしない（規約違反＝成功率も下がる）。
- **券種・支払いは自分で**。自動化しません。
- 各映画館の**利用規約**を必ず確認してから使ってください。
