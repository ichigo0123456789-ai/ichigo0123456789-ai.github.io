# ポップアップガード（Brave / Chrome 用 拡張機能）

漫画サイトとかを見てるときに勝手に出てくるポップアップ・ポップアンダー・全画面オーバーレイ広告をブロックする拡張機能。
**登録したサイトだけ**で動く方式。登録していないサイトにはスクリプトを一切注入しないので、普段のブラウジングには影響しない。
アイコンをクリックすると、今見ているサイトをワンクリックで登録／解除できるし、全体のオン・オフも切り替えられる。

## できること

| 機能 | 内容 |
| --- | --- |
| ポップアップ／ポップアンダー阻止 | ページ内の JavaScript が呼ぶ `window.open()` を全部止める（`_self` など自分自身への遷移は通す） |
| 偽クリック阻止 | スクリプトが勝手に発火させた「人間じゃないクリック」で `target="_blank"` のリンクを開くのを止める |
| 全画面オーバーレイ広告の除去 | 画面の8割以上を覆う固定要素のうち、別ドメインの iframe／巨大リンク／透明クリック罠だけを非表示にする（ログイン画面など入力欄があるものは触らない） |
| 「広告ブロッカーを検出」警告の無効化 | アンチアドブロック系スクリプトが見る `window.adsbygoogle.loaded` を先回りして `true` にし、検出を回避する。それでも出てきた「広告ブロッカーを検出しました」「AdBlock を無効にしてください」系の全画面モーダルは文言で判定して非表示にし、本文に掛けられた `pointer-events:none` も解除する |
| 別タブに移っても画面を隠させない | タブ切替・ウィンドウ切替を検知して本文をぼかしたり暗転させるサイト対策。`document.hidden`／`visibilityState`／`hasFocus()` を「表示中」に偽装し、`window` への `blur`・`document` への `visibilitychange` をサイトのリスナーに届く前に止める。保険として本当に裏にいる間だけ大きな要素の inline blur を剥がす |
| W/A/S/D で矢印キー操作 | ←→でページ送り、↑↓でスクロールするビューワを WASD でも操作できる。W/A/S/D の keydown/keyup を止めて、同じ要素に矢印キーのイベント（`key`/`code`/`keyCode` 付き）を投げ直す。サイトが処理しなかった場合はブラウザの矢印キーと同じようにスクロールする。入力欄にフォーカスがあるときと Ctrl/Alt/Win 付きは変換しない |
| 診断情報 | 小窓の「診断情報を表示」で、注入状況・設定・`adsbygoogle` の状態・画面を覆う要素の判定結果・内部エラーを JSON でコピーできる。うまく動かないときはこれを送る |
| 更新通知 | 小窓を開いたとき GitHub 上の `manifest.json` と比べて、新しいバージョンがあればバナーで知らせる（6時間に1回） |
| ブロック履歴 | タブごとにブロックした URL を記録。アイコンのバッジに件数、小窓から「開く」で自分の意思で開ける |
| オン・オフ切り替え | 小窓の大きいスイッチ、または `Alt+Shift+P`。オフのときはアイコンがグレーになる |
| 対象サイトの登録 | 登録したサイト（サブドメイン含む）でだけ動く。今見ているサイトをスイッチで登録、または入力欄に `example.com` やURLを貼って追加。`www.` は自動で外す |

## インストール（Brave）

ストアには出していないので「パッケージ化されていない拡張機能」として読み込む。

1. この `popup-blocker` フォルダを PC に置く
   - リポジトリを `git clone` するか、GitHub の「Code → Download ZIP」で落として解凍
   - または公開ページ <https://ichigo0123456789-ai.github.io/popup-blocker/> から ZIP をダウンロードして解凍
2. Brave で `brave://extensions/` を開く
3. 右上の「デベロッパーモード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」→ 解凍した `popup-blocker` フォルダを選ぶ
5. ツールバーのパズルアイコンから「ポップアップガード」をピン留めしておくと使いやすい

更新したいときは `brave://extensions/` でこの拡張機能の「更新」（リロード）ボタンを押すだけ。

## 更新を楽にする構成（おすすめ）

Brave の「パッケージ化されていない拡張機能」はフォルダを直接参照するので、
**Google Drive for Desktop（パソコン版ドライブ）で `Claude/popup-blocker` を同期**しておき、
その同期フォルダ（例: `G:\マイドライブ\Claude\popup-blocker`）を読み込むと、
Drive 側のファイルが更新されたら自動で手元にも反映される。あとは `brave://extensions/` で
この拡張機能の「更新」ボタン（↻）を押すか Brave を再起動するだけで新版になる。
「ストリーミング」ではなく「ミラーリング」（オフラインで使用可）にしておくこと。

小窓を開いたときに新しいバージョンがあればバナーで知らせるので、それを見たら ↻ を押せばOK。

## 使い方

- **アイコンをクリック** → 小窓が開く
  - 一番上の大きいスイッチ：全体のオン・オフ
  - 「このサイトでブロックする」：今見ているサイトを登録／解除。ONにするとページが再読み込みされてすぐ効く
  - 「ブロックするサイト」：登録済みの一覧。入力欄に `example.com`（URLを貼ってもOK）を入れて「追加」、✕で解除
  - 「全画面オーバーレイ広告も消す」：誤爆するサイトがあったらここをオフに
  - 「別タブに移っても画面を隠させない」：別タブ／別ウィンドウに移った瞬間にぼかし・暗転するサイト用。デフォルトON
  - 「W/A/S/D で矢印キー操作」：矢印キーでページ送りするビューワを WASD でも動かす。デフォルトON
  - 「『広告ブロッカーを検出』の警告を消す」：Brave Shields を検出して出てくる警告モーダル対策。登録サイトで本物の広告が表示されなくなることがある（検出回避の副作用）ので、気になるときはオフに
  - 「このタブでブロックしたもの」：止めた URL の一覧。必要なら「開く」で新しいタブに開ける
- **`Alt+Shift+P`**：どの画面からでもオン・オフ切り替え（`brave://extensions/shortcuts` で変更可）

## 仕組み（ざっくり）

```
background.js     … 登録サイトの一覧から match pattern を作り、chrome.scripting.registerContentScripts で
                    下の2本を登録サイトにだけ動的に注入する。タブごとのブロック履歴とバッジ、設定の保存、ショートカットキー。
content-main.js   … ページ本体と同じ世界で動く。window.open / click / HTMLElement.click をすり替えてブロック。
                    MutationObserver で全画面オーバーレイを監視して消す。
content-bridge.js … 拡張機能側の世界で動く。設定を読んで content-main.js に渡し、ブロック報告を background に転送。
popup.html/js/css … アイコンを押したときの小窓。
```

ページ側の JavaScript が `window.open` を上書きし直せないよう、プロパティを書き換え不可にしてある。

## できないこと・注意

- **ページ自体が別 URL にリダイレクトする動き**（`location.href = ...`）は止められない。これは拡張機能からは安全にキャンセルできない仕組みのため。
  Brave Shields（アドレスバー右のライオン）を「アグレッシブ」にすると、広告・トラッカー系のリダイレクト先ドメインをかなり止められる。
- `brave://` や Web ストアなどブラウザ内部のページでは動かない（ブラウザの仕様）。
- 登録サイトで決済画面・OAuth ログインなど正規のポップアップが開かないときは、「このサイトでブロックする」を一旦オフにする。
- 登録した直後は、そのサイトを開いているタブを再読み込みすると効き始める（スイッチから登録した場合は自動で再読み込みする）。
- 登録はドメイン単位。`soraraw.com` と `soraraw.net` のように TLD が違うものは別サイト扱いなので、それぞれ登録する（サブドメインは `example.com` の登録で `a.example.com` も対象になる）。同じ運営でも警告の出るページ・出ないページがあるのは、サイト側の設定（`config.json` の `adBlockGuard`）で切り替えているため。
- オーバーレイ判定はかなり控えめにしているが、サイトによっては誤爆する可能性がある。その場合は「全画面オーバーレイ広告も消す」をオフにする。

## 質問にあった URL について

- `tinyurl.com/...?utm_medium=social&utm_source=search.yahoo.co.jp&...` のような URL は、短縮 URL に **アフィリエイト計測用のパラメータ**（utm_*）が大量に付いたもの。
  クリックすると短縮 URL サービス → 計測サーバー → 最終的な電子書籍サイトの順に飛ばされ、途中で「誰の紹介で来たか」が記録される。
- 2 つ目の `ebook.hotgamevr.com/title/...` はその飛び先で、記事風のページから別の電子書籍ストアへ送客してアフィリエイト収入を得る、いわゆる **送客サイト**。
- 見ていたページで URL が勝手に書き換わってポップアップが出るのは、ページ内の広告スクリプトがクリックに便乗してこうした URL を `window.open` で開いたり、`location` を書き換えたりしているため。
  この拡張機能で `window.open` 経由のものは止められる。`location` 書き換え型は Brave Shields の設定強化で対応する。
