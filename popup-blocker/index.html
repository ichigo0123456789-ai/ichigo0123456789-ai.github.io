ポップアップガードBrave / Chrome 用・勝手に開くポップアップ広告をブロックする拡張機能

ダウンロード

popup-blocker.zip をダウンロード ソースを見る（GitHub）

ZIP は GitHub Pages のデプロイ時に自動生成されます。リンク切れのときはリポジトリの「Code → Download ZIP」から落として popup-blocker フォルダを使ってください。

インストール手順（Brave）

  1. ZIP を解凍して popup-blocker フォルダを好きな場所に置く（消すと拡張機能も消えるので注意）
  2. Brave のアドレスバーに brave://extensions/ と入れて開く
  3. 右上の「デベロッパーモード」をオン
  4. 「パッケージ化されていない拡張機能を読み込む」→ popup-blocker フォルダを選ぶ
  5. ツールバーのパズルアイコンから「ポップアップガード」をピン留め

使い方

アイコンをクリック小窓が開く。一番上の大きいスイッチで全サイトのオン・オフ
このサイトでは許可する今見ているサイトだけブロックしない（正規サイトでポップアップが必要なとき用）
全画面オーバーレイ広告も消す画面全体を覆う広告・透明クリック罠を非表示。誤爆するサイトではオフに
このタブでブロックしたもの止めた URL の一覧。必要なら「開く」で自分の意思で開ける
Alt+Shift+Pどこからでもオン・オフ切り替え

できないこと

  • ページ自体が別 URL へ飛ぶリダイレクト（location.href = ...）は止められない。Brave Shields を「アグレッシブ」にすると広告系の飛び先をかなり止められる
  • brave:// などブラウザ内部ページでは動かない
