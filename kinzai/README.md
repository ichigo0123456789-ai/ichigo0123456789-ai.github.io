# 金財試験 過去問道場

金財試験（財務・法務・税務）対策の一問一答アプリ。
過去問道場風のUIで、単元別の順番演習・範囲指定シャッフル・解答履歴の保存に対応。

- 公開URL: `https://ichigo0123456789-ai.github.io/kinzai/`
- 依存なしの静的サイト（HTML/CSS/JS のみ）。ビルド不要。

## 単元構成

各分野（財務・法務・税務）に次の7単元:

| 単元ID | 単元名 | 形式 |
|---|---|---|
| check1〜check3 | 理解度チェックテスト①〜③ | 〇×＋多肢選択の混在 |
| ox1〜ox3 | 〇×問題①〜③ | 〇× |
| practice | 練習問題 | 4択 |

## 問題データの形式

各ファイルは `{ subject, name, units: [...] }` を定義し、
各単元の `questions` に1問1オブジェクトで書く。2形式に対応:

```js
// 〇×問題
{ t: "ox", q: "問題文", a: true, exp: "解説" },
//   a: true = 〇（正しい）, false = ×（誤り）

// 多肢選択（3択・4択どちらも可。選択肢は c の要素数で決まる）
{ t: "mc", q: "問題文", c: ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  a: 1,   // 正解の index（0始まり。a:1 なら②が正解）
  exp: "解説" },
```

### 注意

- **各単元の配列の並び順がそのまま問題番号・学習履歴のIDになります。**
  追加は末尾へ。途中への挿入・削除をすると既存の解答履歴がずれます。
- 解説内の「⚠確度○○％」は解答作成時に確信度が低かった設問の注記。
  テキストで裏取りできたら書き換えてよい。

  解説内に⚠を付記（テキストとの照合推奨）。

## 機能

- **順番に解く**: 分野タブ → 単元選択 → 問題番号グリッド（正誤・チェック状況を色表示）
  から好きな問題を選んで順番に演習
- **シャッフルで解く**: 単元ごとのチェックボックスで出題範囲を指定（分野単位の全選択あり、
  選択状態は保存）、出題範囲フィルタ（すべて / 間違えた問題 / 未解答 / チェック済み）、
  出題数（10 / 25 / 50 / すべて）
- 演習中は画面上部に**途中経過の正答率**を常時表示
- 解答直後に正誤判定＋解説表示、「あとで見直す」チェック
- 結果画面（正答率・解答一覧・間違えた問題の再挑戦）
- 成績画面: **分野ごとの得点率**（直近の解答ベース）＋単元別内訳、履歴リセット
- 解答履歴は `localStorage` に保存（端末ごと。サーバーには送信しない）
- キーボード操作: 〇× = `O` / `X`、多肢選択 = `1`〜`4`、`Enter` = 次へ
