# ログイン・成績同期サーバーのセットアップ手順（無料・約5分）

ID＋PIN（数字4桁）でログインし、成績をアカウントごとにサーバー保存する仕組み。
サーバーには Google Apps Script（GAS）を使い、成績は自分のGoogleドライブの
スプレッドシートに保存される。**費用はかからない。**

## 手順

1. **スプレッドシートを作る**
   [Googleドライブ](https://drive.google.com) → 新規 → Googleスプレッドシート。
   名前は何でもよい（例：`金財道場データ`）。

2. **Apps Script を開く**
   そのスプレッドシートのメニューから「拡張機能」→「Apps Script」。

3. **コードを貼り付ける**
   エディタに最初から入っている `function myFunction() {...}` を全部消して、
   同じフォルダの **`Code.gs` の中身を丸ごと貼り付け**、保存（Ctrl+S）。

4. **ウェブアプリとしてデプロイする**
   右上「デプロイ」→「新しいデプロイ」→ 歯車アイコンで種類「**ウェブアプリ**」を選び、
   - 説明：任意（例：kinzai-sync）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   にして「デプロイ」。
   初回は承認画面が出る：「アクセスを承認」→ 自分のアカウントを選択 →
   「詳細」→「（プロジェクト名）に移動（安全ではないページ）」→「許可」。
   （自作スクリプトをGoogleが未審査というだけの警告。自分のシートに書くだけの内容）

5. **ウェブアプリのURLをコピーする**
   `https://script.google.com/macros/s/XXXXX/exec` という形のURL。

6. **アプリに設定する**
   `kinzai/config.js` の `window.KINZAI_SYNC_URL = "";` の引用符の中にそのURLを貼る
   （またはこのURLをClaudeに渡せば設定してプッシュする）。

これでアプリのヘッダーに「ログイン」ボタンが現れる。

## 動作の仕組み

- 新規登録：ID（半角英数3〜20文字）＋PIN（数字4桁）。「この端末のこれまでの成績を引き継ぐ」に
  チェックすると、それまでのゲスト成績がアカウントに取り込まれる
- 成績は解答のたびに端末へ即保存し、15秒ごと・結果画面・タブを閉じるときにサーバーへ同期
- オフラインでも解ける（端末に保存され、次にオンラインになったとき同期）
- 別の端末でログインすれば同じ成績が引き継がれる（両方の履歴は自動マージ）
- PINを5回連続で間違えると10分間ロック

## 注意（セキュリティの割り切り）

- 4桁PINの簡易ログインなので、銀行のような堅牢さはない。勉強の成績を分ける用途向け
- PINはハッシュ化して保存される（スプレッドシートに生のPINは残らない）が、
  ログイン中の端末にはID・PINが保存される（自動ログインのため）
- スプレッドシート（成績データ）はあなたのGoogleアカウントの中にあり、他人からは見えない

## コードを更新するとき

`Code.gs` を書き換えたら、「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →
バージョン「新バージョン」→「デプロイ」。**URLは変わらない**（「新しいデプロイ」を
作るとURLが変わってしまうので注意）。
